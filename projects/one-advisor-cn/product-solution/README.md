## 三、解决方案总览

### 3.1 产品层（核心功能）

| 模块 | 核心功能 | 解决痛点 |
|------|---------|---------|
| **投研** | 基金风格分析、基金经理画像、深度诊断 | 投研能力弱、选基不准 |
| **交易** | 智能交易引擎、批量下单、智能拆单 | 手工下单效率低 |
| **风控** | 合规规则引擎、AI 风险预警、阈值监控 | 合规审查繁、风控难度大 |
| **运营** | 全链路留痕、审计接口、系统对接 | 系统对接难、留痕审计 |

### 3.2 工具层（效率提升）

| 类别 | 核心工具 | 支撑功能 |
|------|---------|---------|
| **数据** | 基金数据库、标签工厂、数据校验 | 所有分析功能基础 |
| **分析** | 风格分析引擎、风险计算、业绩归因 | 投研 + 风控核心 |
| **自动化** | 合规预审机器人、风险预警机器人、报告生成 | 效率提升关键 |

### 3.3 服务层（增值收入）

| 类别 | 核心服务 | 目标客户 |
|------|---------|---------|
| **培训** | 系统操作、合规、投研能力、风控体系 | 所有机构客户 |
| **咨询** | 技术对接、合规规则定制、风控体系、投顾 | 中大型机构 |
| **定制** | 定制筛选引擎、专属报告、私有化部署 | 大型机构 |

## 四、自运营增长飞轮

```
                    ┌──────────────┐
                    │   推荐 Referral │
                    │  NPS≥30 目标   │
                    └───────┬───────┘
                            │
                            ↓
┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│   拉新        │ →  │   激活        │ →  │   留存        │
│  内容获客     │    │  5 步 onboarding│    │  日报 + 简报   │
│  免费试用     │    │  价值快速感知  │    │  专属客服     │
└──────────────┘    └──────────────┘    └──────────────┘
                            │
                            ↓
                    ┌──────────────┐
                    │   复购 Revenue │
                    │  分层定价     │
                    │  MRR 目标¥500 万│
                    └──────────────┘
```

**五要素目标**：
- 拉新：内容获客 + 免费试用，月新增注册≥1,250
- 激活：5 步 onboarding，试用转化率≥20%
- 留存：日报 + 简报 + 专属客服，30 日留存≥25%
- 复购：分层定价，MRR≥¥500 万（12 个月）
- 推荐：NPS≥30，案例分享 + 行业白皮书

## 五、MVP 实施计划（90 天）

### 5.1 核心功能（P0）

| 模块 | 功能 | 工作量 | 完成时间 |
|------|------|--------|---------|
| 交易 | 批量下单、交易留痕 | 15 人天 | Sprint 2-3 |
| 风控 | 合规规则引擎、预审、预警、拦截 | 42 人天 | Sprint 2-3 |
| 投研 | 基金数据库、筛选器、详情页 | 32 人天 | Sprint 4-5 |
| 运营 | 权限管理、操作日志、审计导出、API 网关 | 38 人天 | Sprint 4-5 |
| 自运营 | 免费试用、新手引导、持仓诊断 | 23 人天 | Sprint 6 |

### 5.2 关键里程碑

| 时间 | 里程碑 | 交付物 |
|------|--------|--------|
| 第 2 周 | 基础设施就绪 | 架构文档、数据接入完成 |
| 第 6 周 | 交易 + 风控核心可用 | 内部测试版 |
| 第 10 周 | MVP 功能完整 | 全功能测试版 |
| 第 12 周 | 合规审核通过 | 可上线版本 |
| 第 13 周 | 灰度发布 | 正式上线 |

### 5.3 资源需求

- **人力**：750 人天（产品 1+ 后端 3+ 前端 2+ 数据 1+ 测试 2+ 其他）
- **技术**：云服务器、数据库、基金数据 API、存储等
- **成本**：¥249,000（90 天）

## 六、功能依赖关系

### 6.1 核心依赖链

```
基金数据库 (I001)
    ↓
┌───────────────────────────────────────┐
│  投研模块：筛选器 → 详情页 → 风格标签  │
│  交易模块：批量下单 → 合规预审 → 拦截  │
│  风控模块：规则引擎 → 阈值监控 → 预警  │
│  运营模块：权限管理 → 操作日志 → 审计  │
└───────────────────────────────────────┘
    ↓
自运营功能：新手引导 → 持仓诊断 → 日报简报
```

### 6.2 关键依赖风险

| 依赖 | 风险等级 | 缓解措施 |
|------|---------|---------|
| 基金数据 API | 高 | 提前签约、备用数据源 |
| 合规审核 | 高 | 早期介入、预沟通 |
| 合规预审→交易 | 高 | 充分测试、降级方案 |
| 风险计算→预警 | 中 | 性能优化、缓冲设计 |

## 七、合规红线

**所有功能必须遵守**：

1. ✅ 不承诺收益、不夸大宣传
2. ✅ 历史业绩标注"不预示未来"
3. ✅ 投研观点标注"仅供参考"
4. ✅ 交易指令全流程留痕
5. ✅ 合规规则可配置、可审计
6. ✅ 用户数据授权明确
7. ✅ 推荐奖励不涉及现金返佣
