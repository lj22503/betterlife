## Vision

### 10x Check

**当前方案**：直接服务 20-50 万资产 C 端用户，3 个月 20 用户，1 万/月收入

**10x 版本**：服务理财师/B 端机构，每个理财师服务 50-100 个 C 端用户
- 3 个月：5 个理财师 → 间接服务 250-500 个 C 端用户
- 12 个月：50 个理财师 → 间接服务 2500-5000 个 C 端用户
- 收入：50 理财师 × 5000 元/月 = 25 万/月 + AUM 分成

### Platonic Ideal

**"中国版 Orion"的终极形态（36 个月）：**

```
┌─────────────────────────────────────────────────────────┐
│                    中国版 Orion                          │
├─────────────────────────────────────────────────────────┤
│  客户：1000+ 理财师/投顾团队/家族办公室                    │
│  终端用户：间接服务 5 万 + 投资者                         │
│  管理 AUM：100 亿 +                                      │
│  价值：AI 增强 + 组合管理 + 合规报告 + 客户门户 + 交易执行   │
│  收费：SaaS 订阅（999-9999 元/月）+ AUM 分成（0.05%）      │
│  护城河：数据网络效应 + 合规牌照合作 + 生态整合            │
│  退出：被持牌机构收购 or 独立上市                         │
└─────────────────────────────────────────────────────────┘
```

**用户感受：**
> "这个系统比我更懂我的客户——它知道什么时候该调仓，什么时候该安抚客户情绪，什么时候该推荐新产品。我不是被替代，我是被增强了。"

## Accepted Scope（本计划范围）

### Phase 1（0-3 个月）：需求验证

**目标**：验证理财师愿意为 AI 投顾工具付费

**任务**：
1. **第 1-2 周**：访谈 10 个理财师
   - 确认痛点（时间不够？客户太多管不过来？）
   - 确认付费意愿（现在为什么付钱？付给谁？）
   - 确认决策流程（谁拍板？多久决定？）

2. **第 3-4 周**：手动服务 5 个理财师（免费）
   - 用飞书 +Excel+AI 提供服务
   - 每周生成客户持仓分析报告
   - 关键时点提醒（亏 10%/赚 15%）
   - 归因报告（建议 vs 实际收益）

3. **第 5-8 周**：搭建基础工具
   - 持仓同步（截图/Excel 导入）
   - AI 初步分析→人工审核→发送建议
   - 客户门户（简易版，飞书表单）
   - 归因报告自动生成

4. **第 9-12 周**：收费测试
   - 从 5 个免费转 3 个付费
   - 定价测试：999 vs 2999 vs 5999 元/月
   - 收集改进建议

**成功标准**：
- ✅ 10 个访谈完成，8 个表示有需求
- ✅ 5 个免费用户，4 个每周主动使用
- ✅ 3 个付费转化，续费率>80%
- ✅ 月收入达到 1 万+

---

### Phase 2（3-12 个月）：产品化

**目标**：从手动服务转向平台化

**任务**：
1. 搭建基础平台（小程序/H5+ 后端）
2. 自动化持仓同步（对接天天基金/蚂蚁 API 或截图识别）
3. AI 建议自动生成（减少人工审核）
4. 客户门户完善（独立 APP/小程序）
5. 合规合作对接（1-2 家持牌机构）

**成功标准**：
- 50 个付费理财师
- 月收入 25 万+
- 续费率>80%
- 间接服务 2500+ C 端用户

---

### Phase 3（12-36 个月）：规模化

**目标**：从独立理财师扩展到机构客户

**任务**：
1. 机构版产品（定制化 + 私有化部署）
2. 与大型持牌机构深度合作
3. 申请相关资质（如需要）
4. 团队扩张（销售 + 客户成功 + 技术）

**成功标准**：
- 500+ 理财师/机构客户
- 月收入 100 万+
- 间接服务 2.5 万+C 端用户
- 管理 AUM 100 亿+

## 单位经济模型

### 单理财师模型（Phase 1）

| 项目 | 金额 |
|------|------|
| 收费 | 5000 元/月 |
| 服务成本 | 1000 元/月（人工审核 + 工具） |
| 获客成本 | 5000 元（一次性，摊 10 个月=500 元/月） |
| 毛利 | 3500 元/月（70%） |
| LTV | 3500 × 12 个月 × 80% 留存 = 3.36 万 |
| LTV/CAC | 3.36 万 / 5000 = 6.7x ✅ |

### 规模模型（Phase 2，50 个理财师）

| 项目 | 金额 |
|------|------|
| 月收入 | 50 × 5000 = 25 万 |
| AUM 分成 | 50 理财师 × 5000 万 AUM × 0.05%/月 = 12.5 万 |
| 总收入 | 37.5 万/月 |
| 成本 | 人力 15 万 + 技术 5 万 + 合规 3 万 + 获客 6 万 = 29 万 |
| 利润 | 8.5 万/月（23% 净利率） |

### 现有玩家分析

| 竞品 | 定位 | 目标用户 | 收费模式 | 为什么没做大 |
|------|------|----------|----------|--------------|
| 且慢（蛋卷） | 基金投顾平台 | C 端用户 + 理财师 | AUM 分成 | 有牌照，但服务深度不够 |

### 我们的差异化

| 维度 | 竞品 | 我们 |
|------|------|------|
| 核心价值 | 组合构建/交易执行 | **用户视角报告 + 行为纠偏 + 陪伴** |
