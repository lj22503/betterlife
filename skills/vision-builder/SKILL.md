# 愿景构建器 🔭

**基于领导力经典理论**

---

## 📋 功能描述

帮助用户构建团队愿景，提升领导力。

**适用场景：**
- 构建团队愿景
- 团队管理
- 领导力发展

---

## 🎯 核心功能

### 1. 核心方法

**步骤：**
```
1. 评估当前状态
2. 设定目标
3. 采取行动
4. 反馈优化
```

---

## ⚠️ 常见错误

**错误 1：微观管理**
```
问题：
• 过度干预下属工作
• 不信任团队成员

解决：
✓ 授权而非控制
✓ 信任团队成员
✓ 关注结果而非过程
```

**错误 2：忽视团队文化**
```
问题：
• 只关注业绩
• 忽视文化建设

解决：
✓ 构建团队文化
✓ 关注团队成员成长
✓ 建立共同价值观
```

## 📚 核心理念

**关键洞察：**
1. 构建团队愿景
2. 领导力是可以学习的
3. 以身作则，共启愿景
4. 激励人心，使众人行

**健康公式：**
```
卓越领导力 = 愿景 + 信任 + 行动 + 激励
```

---

*领导力原则：
以身作则，共启愿景；
挑战现状，使众人行；
激励人心。
领导力不是职位，
而是影响他人共同实现目标的能力。* 🔭
