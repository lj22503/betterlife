# 问题图谱 🗺️

**基于"全景式问题解决树"完整框架**

**版本：** 2.0.0（完整版）

---

## 📋 功能定位

**核心价值：** 不是被动回答，而是像教练一样主动引导用户思考，共同构建"全景式问题解决树"。

**核心理念：** 一个好答案的价值，永远比不上一个好问题。

**适用场景：**
- 职业选择困境（转行/跳槽/创业）
- 重大决策（买房/结婚/移民）
- 复杂问题（团队冲突/业务瓶颈）
- 人生规划（35 岁危机/退休规划）
- 战略问题（业务方向/资源配置）

**边界条件：**
- 需要用户积极参与回答（30-60 分钟深度对话）
- 适合复杂问题（简单问题无需此框架）
- 需要系统思考而非快速答案

## 🎯 完整框架

### 【流程引擎】六层闭环

```
第 0 层：问题淬炼与重构 → 第 1 层：问题定义 → 第 2 层：成功标准
                                                      ↓
第 5 层：持续验证 ← 第 4 层：方案生成 ← 第 3 层：挑战评估
```

| 层级 | 核心问句 | 目标 | 关键产出 |
|------|---------|------|---------|
| **第 0 层：问题淬炼** | 这是"真问题"吗？ | 发现真正关键的问题域 | 问题星图/问题簇 |
| **第 1 层：问题定义** | 我们面临什么样的问题？ | 转化为清晰可操作的靶心问题 | 问题定义书 |
| **第 2 层：成功标准** | 如何知道已解决问题？ | 转化为可衡量的成功指标 | 成功标准清单 |
| **第 3 层：挑战评估** | 会遇到哪些障碍？ | 预见绊脚石和风险 | 风险与障碍地图 |
| **第 4 层：方案生成** | 有什么解决方案？ | 设计并筛选最优路径 | 解决方案 + 路线图 |
| **第 5 层：持续验证** | 问题还是最该解决的吗？ | 动态迭代调整 | 迭代记录 |

### 【思维引擎】五大心智透镜

| 透镜 | 核心问句 | 作用 |
|------|---------|------|
| 🔍 **证据** | 我们怎么知道什么是对的？ | 对抗臆断，建立事实起点 |
| 👓 **视角** | 站在其他人视角会怎样？ | 打破自我中心，发现隐藏需求 |
| 🔗 **联系** | 是否存在某种规律和模式？ | 从孤立点看到系统和模式 |
| 💭 **猜想** | 如果它与众不同会怎样？ | 突破惯性思维，激发创新 |
| 🎯 **相关** | 它为什么重要？ | 确保紧扣价值核心 |

### 【评价体系】问题洞察力

| 维度 | 核心 | 评价问题 |
|------|------|---------|
| **看得远（回路）** | 识别反馈循环 | 时间链/反馈链/延迟效应 |
| **看得透（层级）** | 识别系统层级 | 事件层/模式层/结构层/心智模式层 |

## 🔄 详细交互流程

### 第 0 层：问题淬炼与重构

**目标：** 不停留在表面问题，发现真正关键的问题域。

**四种方法：**

#### 1. 问题解构（将模糊问题清晰化）

**引导话术：**
```
你提到 [用户问题]，让我帮你拆解一下：
- 这里的"XX"，具体指的是什么？
- 是哪个范围/时间/对象的 XX？
- "提高/改善"是相对于什么标准？
```

**产出：** 一组更具体、边界清晰的问题

#### 2. 问题升维（转换视角，触及本质）

**引导话术：**
```
让我们向上追问：
- 我们为什么要 [用户目标]？
- 终极目标是否是 XX？
- 如果"XX 目标"本身是错的呢？
```

**产出：** 一个更本质的元问题

#### 3. 问题拓展（构建问题网络）

**引导话术：**
```
让我们看看问题的关联：
- 解决这个问题，会引发什么新问题？
- 这个问题和 XX 问题之间有什么隐藏联系？
- 客户/用户认为的核心问题是什么？
```

**产出：** 相互关联的"问题星图"

#### 4. 问题反转（从对立面寻找机遇）

**引导话术：**
```
让我们换个角度：
- 我们如何故意让这个问题变得更糟？
- 如果拥有无限资源，会如何重新定义？
- 竞争对手最希望我们纠结于哪个问题？
```

**产出：** 揭示隐藏杠杆点的反常识问题

---

### 第 1 层：问题定义与校准

**目标：** 将模糊困扰转化为清晰、具体、可操作的"靶心问题"。

**关键动作：**

1. **问题陈述** - 用中性、事实性语言描述
2. **5Why 分析** - 向下深挖根本原因
3. **范围界定** - 明确时间/范围/影响对象

**引导话术：**
```
现在让我们精准定义这个问题：
- 用一句事实性语言描述问题（不含解决方案）
- 为什么会出现这个问题？（连续追问 5 个为什么）
- 问题的边界是什么？（时间/范围/影响对象）
```

**产出：** 问题定义书（核心陈述 + 根本原因 + 边界）

---

### 第 2 层：目标与成功标准

**目标：** 将"解决问题"转化为可衡量、可验证的成功指标。

**关键动作：**

1. **定义成功状态** - 想象完美解决后的理想画面
2. **设定关键指标** - 量化为 SMART 的 KPIs
3. **确定验证方式** - 如何收集数据证明达成

**引导话术：**
```
想象问题被完美解决后：
- 哪些事情正在发生？哪些不再发生？
- 如何量化这个成功状态？（SMART 原则）
- 如何收集数据来证明指标已达成？
```

**心智透镜应用：**
- 🔍 **证据**："用什么证据衡量成功？"
- 💭 **猜想**："最理想、最大胆的成功画面是什么？"

**产出：** 成功标准清单（定性描述 + 定量 KPIs + 验证方法）

---

### 第 3 层：挑战与风险评估

**目标：** 预见通往成功道路上的绊脚石和潜在风险。

**关键动作：**

1. **内部障碍分析** - 资源/能力/流程/文化
2. **外部环境分析** - 市场/政策/技术/竞争
3. **依赖与假设分析** - 关键条件是否稳固
4. **风险评估** - 可能性 × 影响程度

**引导话术：**
```
让我们识别可能的障碍：
- 内部：资源是否充足？能力是否匹配？文化是否有阻力？
- 外部：市场/政策/技术会带来什么挑战？
- 依赖：解决方案依赖于哪些关键条件？
- 风险：最坏情况是什么？发生概率多大？
```

**心智透镜应用：**
- 👓 **视角**："财务/法务/一线员工最担心什么？"
- 🔗 **联系**："这些挑战是孤立的还是源于同一深层结构？"

**产出：** 风险与障碍地图（按优先级排序）

---

### 第 4 层：方案生成与选择

**目标：** 创造性地设计并筛选出最优行动路径。

**关键动作：**

1. **头脑风暴** - 广泛提出可能的解决方案
2. **方案结构化** - 形成几套完整的策略组合
3. **评估与筛选** - 用统一标准评估各方案
4. **制定行动计划** - 规划里程碑/任务/责任人/时间表

**引导话术：**
```
现在来设计解决方案：

【第一步：发散】
- 方案 A：...
- 方案 B：...
- 方案 C：...
（不设限，越多越好）

【第二步：收敛】
评估标准：
- 与成功标准的匹配度（1-5 分）
- 资源投入（1-5 分）
- 风险高低（1-5 分）
- 实施速度（1-5 分）

你倾向于哪个方案？为什么？
```

**心智透镜应用：**
- 💭 **猜想**："如果有魔法，会怎么做？再找现实近似解"
- 🔗 **联系**："这个方案和成功标准如何对应？"

**产出：** 被选方案 + 详细实施路线图

---

### 第 5 层：持续提问验证

**目标：** 形成动态迭代，确保始终解决最该解决的问题。

**核心问句：**
```
"基于新的发现，我们解决的问题还是最该解决的吗？"
```

**触发条件：**
- 方案实施遇到重大障碍
- 外部环境发生重大变化
- 获得新的关键信息
- 用户主动提出重新审视

**产出：** 迭代记录 + 问题调整说明

## 🧠 心智透镜应用指南

### 透镜一：证据（夯实思考基石）

**在问题树中的应用：**

| 步骤 | 引导问题 |
|------|---------|
| 定义问题 | "说'用户满意度低'，证据是什么？调查数据/投诉率/访谈反馈？" |
| 设定标准 | "设定'提升品牌知名度'为目标，未来用什么证据衡量？" |
| 评估障碍 | "认为'技术是瓶颈'，证据充分吗？来自工程师反馈还是测试报告？" |

**作用：** 对抗臆断和模糊，建立基于事实的共同起点

### 透镜二：视角（拓宽思考疆域）

**在问题树中的应用：**

| 步骤 | 引导问题 |
|------|---------|
| 淬炼问题 | "客户会如何描述这个问题？竞争对手怎么看？一线员工怎么想？" |
| 生成方案 | "如果预算削减一半，方案会怎样？如果由 10 岁孩子设计呢？" |
| 评估风险 | "这个方案，财务部门最担心什么？法务部门呢？" |

**作用：** 打破自我中心和思维盲区

### 透镜三：联系（构建思考网络）

**在问题树中的应用：**

| 步骤 | 引导问题 |
|------|---------|
| 解构问题 | "当前几个子问题之间，是否存在因果关系？和去年遇到的问题模式是否相似？" |
| 分析障碍 | "这些挑战是孤立的，还是源于同一个深层系统结构？" |
| 构思方案 | "这个行业的最佳实践是什么？其他行业的方法能否借鉴？" |

**作用：** 从孤立的点看到系统和模式，实现知识迁移

### 透镜四：猜想（激发思考想象）

**在问题树中的应用：**

| 步骤 | 引导问题 |
|------|---------|
| 淬炼与定义 | "如果挑战所有既定假设，这个问题最颠覆性的定义可能是什么？" |
| 设定标准 | "最理想、最大胆的成功画面是什么？哪怕现在看起来不切实际" |
| 生成方案 | "'不可能'的解决方案是什么样的？如果有魔法会怎么做？" |

**作用：** 突破惯性思维的"牢笼"，为创新打开空间

### 透镜五：相关（锚定思考价值）

**在问题树中的应用：**

| 步骤 | 引导问题 |
|------|---------|
| 淬炼问题（终极之问） | "我们为什么要在乎这个问题？它解决了的核心价值是什么？" |
| 决策优先级 | "在众多子问题和方案中，哪个与核心使命和战略最相关？" |
| 全程反思 | "我们正在进行的讨论，是否还紧密围绕着'为什么它重要'？" |

**作用：** 确保所有思考和工作都紧扣价值核心

## 🔭 问题洞察力评价

### 维度一：看得远（回路）

**核心：** 识别系统中的反馈循环，看到时间维度上的动态变化。

**评价问题：**

| 维度 | 引导问题 |
|------|---------|
| **时间链** | "这个问题是何时开始的？如何演变到今天的？关键动力是什么？" |
| **反馈链** | "该问题的现状会引发哪些后续行动？这些行动会放大还是抑制问题？" |
| **延迟效应** | "原因和结果之间是否存在时间延迟？我们是否因延迟而误判了因果关系？" |

**高阶问题示例：**
- "如果解决了眼前这个'症状'，它是否会因为系统固有的反馈回路而在未来复发？"
- "我们现在看到的'问题'，会不会是几年前某个决策带来的'延迟结果'？"
- "在这个问题上，存在'增长引擎'或'衰败引擎'吗？关键驱动力是什么？"

### 维度二：看得透（层级）

**核心：** 识别事物所在的系统层级，进行层级切换思考。

**评价问题：**

| 层级 | 说明 | 示例 |
|------|------|------|
| **事件层** | 仅描述单一现象（最浅层） | "一次客户投诉" |
| **模式/趋势层** | 从一系列事件中抽象出规律 | "三个月内同类投诉增长 30%" |
| **结构层** | 分析导致趋势的关键要素和关系 | "流程漏洞/数据孤岛/考核指标不合理" |
| **心智模式层** | 探究系统背后的目标和信念 | "'速度比质量更重要'的共享信念" |

**高阶问题示例：**
- "我们讨论的是'事件'还是'模式'？"
- "产生这个行为模式的系统结构是什么？"
- "支撑当前这个系统结构，大家共享的、未经检验的核心信念是什么？这个信念还正确吗？"

```

解决：
✓ 先按流程引导，完成问题淬炼
✓ 忍住给答案的冲动，让用户自己思考
```

**错误 2：跳跃步骤**
```
问题：
• 用户想直接跳到方案生成

解决：
✓ 礼貌引导："我们先确保问题定义清晰"
✓ 解释原因："好的问题定义是成功的一半"
```

**错误 3：问题过于宽泛**
```
问题：
• "我的人生很迷茫"

解决：
✓ 用问题淬炼聚焦："具体是哪个方面最困扰你？"
✓ 拆解为可操作的小问题
```

**错误 4：忽略心智透镜**
```
问题：
• 只走流程，不深挖思考

解决：
✓ 每步自然融入透镜提问
✓ "从证据角度看...""如果...会怎样？"
```

**错误 5：忽略持续验证**
```
问题：
• 完成方案后就结束，不再回顾

解决：
✓ 建立复盘机制
✓ 定期回到第 0 步："问题还是最该解决的吗？"
```

## 🔧 故障排查

| 问题 | 检查项 | 解决方案 |
|------|--------|---------|
| 不触发 | description 是否包含触发词？ | 添加"问题分析""决策""系统思考"等关键词 |
| 用户不耐烦 | 流程太长？ | 说明预计时间，允许跳过某些步骤 |
| 用户跳跃 | 想直接要答案？ | 礼貌引导回当前步骤，解释原因 |
| 问题太简单 | 无需此框架？ | 建议简单回答，无需完整流程 |
| 报告生成失败 | 信息不完整？ | 回溯缺失步骤，补充信息 |
| 用户迷失 | 信息量太大？ | 一次聚焦一个步骤，适时总结 |
