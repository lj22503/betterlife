# 才能地图绘制器 🗺️

**基于《找到自己想做的事情》核心理念**

---

## 📋 功能描述

帮助用户发现自己无意识的才能和擅长之事，将缺点重新定义为优点。

**适用场景：**
- 不知道自己擅长什么
- 觉得自己没有特长
- 想发挥优势而非克服缺点
- 职业优势定位

---

## 🎯 核心功能

### 1. 才能 5 问探索法

1. 迄今为止充实的体验是什么？
2. 最近让你烦躁的事是什么？
3. 身边人认为你的长处是什么？
4. 辞职前留恋的工作部分是什么？
5. 至今取得过什么成果？如何做到的？

### 2. 才能 100 例清单

提供 100 个才能描述，每个包含长处和短处。

### 3. 缺点重新定义

将"和别人长时间在一起会很累"重新定义为"可以一个人专注做事情"。

### 4. 个人使用说明书

归纳自己的长处，写一份《自己的使用说明书》。

---

## 📚 政策依据

**核心理论：**
- 《找到自己想做的事情》- 八木仁平
- 擅长的事=无意识的习惯
- 发挥长处优于克服短处

**关键概念：**
- 才能是无意识的习惯
- 缺点换个视角是优点
- 强化长处成为无可替代的人

## ⚠️ 常见错误

**错误 1：期望过高**
```
问题：
• 期望一次使用就彻底改变

解决：
✓ 技能是辅助工具，需要持续实践
✓ 设定合理期望，小步迭代
```

**错误 2：脱离场景**
```
问题：
• 不考虑具体场景直接套用

解决：
✓ 先说明你的具体情况
✓ 根据建议调整适配
```

```

✓ 先确认适用场景
```
