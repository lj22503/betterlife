# 价值观探索器 🧭

**基于《找到自己想做的事情》核心理念**

---

## 📋 功能描述

帮助用户探索核心价值观，找到指引人生的指南针和工作目的。

**适用场景：**
- 人生方向迷茫
- 职业选择困难
- 价值观冲突
- 重大决策前

---

## 🎯 核心功能

### 1. 价值观 5 步探索法

1. 回答 5 个问题，找出价值观关键词
2. 形成价值观思维导图
3. 从"以他人为中心"转为"以自我为中心"
4. 列出价值观排序，确定优先级
5. 确定工作目的

### 2. 5 个核心问题

1. 你尊敬的人是谁？尊敬他们哪些地方？
2. 童年和青春期影响最大的经历是什么？
3. 你觉得现在的社会有什么不足？
4. 周围人认为你看重什么？
5. 你想传授给别人什么？

### 3. 价值观 100 例清单

提供 100 个价值观关键词供参考选择。

---

**核心理论：**
