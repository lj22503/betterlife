## 使用说明

1. 选择一个必须清理的房间
2. 将这间屋里的所有东西，逐一填写到其所属的类别下面
3. 问自己，"必需品"一栏下列出的所有东西是否确为必需品
4. 如果不是，将其重新归类到"非必需品"或是"废品"

**审视问题**：
- 这件物品真的是生存必需吗？
- 如果没有它，生活会受到什么影响？
- 是否有替代品？

---

### 🏠 非必需品

**定义**：理想状况下，你大部分的物品都应属于这一类。它们是你生活中"想要"的东西，可以增加生活的价值。

| 物品 | 数量 | 使用频率 | 增添价值 (1-10) | 备注 |
|------|------|---------|----------------|------|
| | | | | |
| | | | | |
| | | | | |

**审视问题**：
- 这件物品提升了我的生活品质吗？
- 使用频率如何？
- 是否值得占用空间？

---

### 🗑️ 废品

**定义**：不幸的是，你拥有的几乎所有东西，可能实际上都属于这类。它们是你"喜爱"的藏品，或者更准确地说，是你"自认为"喜爱的藏品。

| 物品 | 数量 | 最后使用时间 | 废品原因 | 处理方式 |
|------|------|-------------|---------|---------|
| | | | | |
| | | | | |
| | | | | |

**废品原因**：
- 超过 90 天未使用
- 如果自燃会感到宽慰
- 只是"以防万一"但 20/20 能买回
- 冲动购买后悔
- 不再符合价值观

**处理方式**：
- 丢弃
- 捐赠
- 售卖（30 天期限）
- 回收
