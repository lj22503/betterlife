# 职业重塑器 🔄

**基于《远见：如何规划职业生涯 3 大阶段》核心理念**

---

## 📋 功能描述

帮助用户在机器时代重塑职业，培养未来所需技能，保持竞争力。

**适用场景：**
- 职业转型
- 中年危机
- AI 时代焦虑
- 技能更新

---

## 🎯 核心功能

### 1. 机器替代风险评估

**容易被替代的工作特征：**
- 重复性高
- 规则明确
- 不需要创造力
- 不需要情商

**不易被替代的技能：**
- 情商
- 创造力
- 协作能力
- 建立信任关系

### 2. 未来技能培养

**四大核心技能：**
1. **情商** - 理解和管理情绪
2. **创造力** - 产生新想法
3. **协作能力** - 团队合作
4. **建立信任关系** - 人际关系

### 3. 未来工作趋势

**趋势：**
- 创业和自由职业蓬勃发展
- 工作目标更多样化
- 在线平台成为主要求职场所
- 退休后继续工作获得稳定收入

### 4. 12 种幸福策略

**来自《幸福有方法》：**
1. 表达感恩
2. 培养乐观心态
3. 避免思虑过度和社会攀比
4. 多行善事
5. 维护人际关系
6. 发展合作策略
7. 学会原谅
8. 增加心流体验
9. 享受生活乐趣
10. 努力实现目标
11. 信仰宗教，寻找精神寄托
12. 关注身体健康

## ⚠️ 常见错误

**错误 1：期望过高**
```
问题：
• 期望一次使用就彻底改变

解决：
✓ 技能是辅助工具，需要持续实践
✓ 设定合理期望，小步迭代
```

**错误 2：脱离场景**
```
问题：
• 不考虑具体场景直接套用

解决：
✓ 先说明你的具体情况
✓ 根据建议调整适配
```

**错误 3：忽略边界条件**
```
问题：
• 在不适用的场景强行使用

解决：
✓ 先确认适用场景
✓ 超出范围时寻求专业帮助
```
