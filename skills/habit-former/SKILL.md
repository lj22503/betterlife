# 习惯养成器 📅

**基于《人性的弱点：如何待人接物》（卡耐基）**

---

## 📋 功能描述

帮助用户把建议变成习惯，提升人际交往能力。

**适用场景：**
- 把建议变成习惯
- 改善人际关系
- 提升领导力

---

## 🎯 核心功能

### 1. 核心方法

**步骤：**
```
1. 理解原则
2. 练习应用
3. 形成习惯
4. 持续改进
```

---

## ⚠️ 常见错误

**错误 1：批评指责**
```
问题：
• 批评带来的并不是改变，而是怨恨
• 激起抵触，让人急于辩白

解决：
✓ 不要批评，不要指责，不要抱怨
✓ 改变自己远比改变他人令你受益更多
✓ 智者以理解代替指责
```

## 📚 核心理念

**关键洞察：**
1. 把建议变成习惯
2. 不要批评，不要指责，不要抱怨
3. 真心实意地感谢他人、赞美他人
4. 站在他人角度考虑，真诚地帮助他人

---

*个人的成功只有百分之十五是源自专业能力，
另外的百分之八十五则来自人格特质和领导能力。
这世界里从不缺少贪婪成性、自私自利之人。
能够站在他人角度考虑、真诚地帮助他人的人却少之又少。
因此后者必将卓然于众，无可匹敌。* 📅
